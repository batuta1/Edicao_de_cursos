# Análise crítica — Hands-on v1.0

## Diagnóstico

| Critério | Avaliação | Correção aplicada |
|---|---|---|
| Executabilidade | Parcial | Passos reordenados e resultados observáveis incluídos |
| Pré-requisitos | Parcial | Conta, modelo, arquivo público e credenciais explicitados |
| Navegação | Risco moderado | Breadcrumbs mantidos apenas onde sustentados pela fonte |
| Segurança | Insuficiente | Menor privilégio, confirmação e human review incorporados |
| Troubleshooting | Insuficiente | Sintomas e correções adicionados a cada oficina |
| Autonomia | Adequada após revisão | Projeto final com checklist e critérios de conclusão |

## Matriz de achados

- H1 — AI Agent exige pelo menos uma tool; destino: Oficina 1.
- H2 — Session Key inadequada mistura conversas; destino: Oficina 2.
- H3 — Simple Memory não é indicada para queue mode; destino: Oficina 2.
- H4 — RAG precisa de ingestão e consulta distintas; destino: Oficina 3.
- H5 — Ferramenta de escrita precisa de escopo mínimo e aprovação; destino: Oficina 4.
- H6 — Retry pode duplicar ações; destino: Oficina 4 e Projeto Final.
- H7 — Executions deve registrar evidências de teste; destino: todas as oficinas.

## Parecer

A estrutura é aprovada com quatro oficinas cumulativas e um projeto final autônomo. Rótulos de interface devem ser confirmados antes da publicação.
