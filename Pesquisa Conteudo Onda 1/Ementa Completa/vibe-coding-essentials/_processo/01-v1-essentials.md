# Módulo 1 — O que é vibe coding

> Ponto de partida.

### Objetivos de Aprendizagem

Ao final deste módulo, o participante deverá ser capaz de:

- definir vibe coding;
- distinguir vibe coding de no-code.

### Texto Descritivo

Denomina-se vibe coding a criação de software por meio da descrição do resultado desejado em
linguagem natural, aceitando-se o código produzido por inteligência artificial. O termo foi
popularizado por Andrej Karpathy em fevereiro de 2025 e escolhido palavra do ano de 2025 pelo
dicionário Collins.

Distingue-se do no-code, em que o usuário monta a aplicação com componentes visuais. O Lovable é uma
plataforma de vibe coding que gera aplicações completas a partir de conversa.

### Exercício Prático

**Questão (5 min)**

Vibe coding é: a) programar linha a linha; b) criar software por linguagem natural; c) usar planilhas.

**Gabarito:** b.

# Módulo 2 — Primeiro app no Lovable

> Pressupõe o conceito; passa à prática.

### Objetivos de Aprendizagem

Ao final deste módulo, o participante deverá ser capaz de:

- criar um projeto no Lovable;
- gerar a primeira versão de um app.

### Texto Descritivo

Para começar, acessa-se `lovable.dev`, cria-se uma conta e descreve-se o aplicativo desejado na caixa
de prompt. O Lovable gera o código e exibe uma prévia. Recomenda-se usar o Agent mode para que a
ferramenta construa o aplicativo de ponta a ponta.

### Exercício Prático

**Primeiro app (15 min)**

1. Criar conta no Lovable.
2. Digitar: "Crie um app de tarefas com login e banco de dados".
3. Testar a prévia.

**Critério de êxito:** o app aparece na prévia.

# Módulo 3 — Banco de dados e login

> Pressupõe o app gerado; acrescenta persistência.

### Objetivos de Aprendizagem

Ao final deste módulo, o participante deverá ser capaz de:

- adicionar banco de dados;
- adicionar autenticação.

### Texto Descritivo

O Lovable integra-se ao Supabase, serviço de banco de dados e autenticação. Para conectá-lo, cria-se
uma conta no Supabase e vincula-se o projeto. Em seguida, pede-se ao Lovable que crie as tabelas e o
login.

### Exercício Prático

**Banco e login (15 min)**

1. Conectar o Supabase.
2. Pedir a tabela de tarefas e o login.
3. Criar uma conta e adicionar tarefas.

**Critério de êxito:** as tarefas permanecem após recarregar a página.

# Módulo 4 — Publicar e iterar

> Pressupõe o app funcional; leva-o ao público.

### Objetivos de Aprendizagem

Ao final deste módulo, o participante deverá ser capaz de:

- publicar o aplicativo;
- fazer alterações.

### Texto Descritivo

Clica-se em Publish para gerar um endereço público. Alterações posteriores podem ser feitas por novos
prompts. Recomenda-se testar o aplicativo antes de divulgá-lo.

### Exercício Prático

**Publicação (10 min)**

1. Clicar em Publish.
2. Abrir o endereço.
3. Pedir uma alteração de cor.

**Critério de êxito:** o app está no ar.
