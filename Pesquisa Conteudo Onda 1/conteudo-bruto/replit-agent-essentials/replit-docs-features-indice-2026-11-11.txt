# Replit: English Features Features

## Features

### Workspace & Admin

- [Workspaces](https://docs.replit.com/features/collaboration/workspaces.md): Learn how Workspaces on Replit organize your projects, teammates, settings, and billing — and when to use a Personal Workspace versus a Team Workspace.
- [Personal & Team Workspaces](https://docs.replit.com/features/collaboration/team-workspaces.md): Understand the difference between personal and team workspaces, create a team workspace, and invite members to build together.
- [Workspace geography](https://docs.replit.com/features/collaboration/workspace-geography.md): Choose where development resources for a Workspace and its new Projects are hosted.
- [Workspace Settings](https://docs.replit.com/features/collaboration/workspace-settings.md): Find Workspace settings, manage delegated controls, and learn how account policies, Workspace exceptions, and Workspace managed settings work together.
- [Enterprise model controls](https://docs.replit.com/features/collaboration/enterprise-model-controls.md): Choose which Agent model providers and models are available in each Enterprise Workspace.
- [Admin API](https://docs.replit.com/teams/admin-api.md): Use the Replit Enterprise Admin API to access account usage, workspaces, members, and projects programmatically.

### Chats and routines

- [Chats](https://docs.replit.com/features/chats-and-routines/chats.md): Use chats to ask questions, explore information, run Routines, update your projects, and describe useful outcomes.
- [Routines](https://docs.replit.com/features/chats-and-routines/routines.md): Schedule recurring work from a chat and receive the results in the same thread.
- [Sharing chats and assets](https://docs.replit.com/features/chats-and-routines/sharing.md): Share a whole chat or an individual asset with teammates in your workspace. Review access, understand development URL risks, and remove sharing permissions.

### Projects & artifacts

- [What's a Project?](https://docs.replit.com/features/projects-and-artifacts/projects.md): Learn what projects are on Replit — the container for everything you build, from web apps and mobile apps to slide decks and animated videos.
- [What's an Artifact?](https://docs.replit.com/features/projects-and-artifacts/artifacts.md): Artifacts are publishable outputs on Replit — web apps, mobile apps, slide decks, animations, data visualizations, 3D games, and designs you can publish and share.
- [Multiple Artifacts vs. Separate Projects](https://docs.replit.com/features/projects-and-artifacts/multiple-artifacts-vs-projects.md): Learn when to combine artifacts in one project and when to create separate projects on Replit.
- [Updating older projects for multiple artifact support](https://docs.replit.com/features/projects-and-artifacts/updating-projects-for-multiple-artifacts.md): Add a second artifact to an older Replit project with a one-time structural update that preserves your URL, data, and deployment.
- [Remix an app](https://docs.replit.com/features/projects-and-artifacts/remix-an-app.md): Create your own copy of a public Replit App or template to explore, customize, and build on in your workspace.

### Project editor

- [Editor & Tools](https://docs.replit.com/features/editor/editor-and-tools.md): Learn about the tools available in the Project Editor — the editor, preview, console, shell, and more.
- [Preview](https://docs.replit.com/features/editor/preview.md): Learn how to use Preview to view and interact with your web app as you build.
- [Keyboard Shortcuts](https://docs.replit.com/features/editor/keyboard-shortcuts.md): Learn how to view, add, and modify keyboard shortcuts that can boost your productivity in Replit.
- [User Settings](https://docs.replit.com/features/editor/user-settings.md): Learn how to personalize the Project Editor with user settings that apply across all your apps.

### Agent

- [Replit Agent](https://docs.replit.com/features/agent/overview.md): Replit Agent turns your ideas into apps, designs, slides, and more, all from plain language. No coding required.
- [Plan Mode](https://docs.replit.com/features/agent/plan-mode.md): Learn how to use Plan mode to brainstorm and plan with Agent before changing your app's code or data.
- [Agent Modes](https://docs.replit.com/features/agent/agent-modes.md): Learn how to choose between Free Mode, Power Mode, and Max Mode for your Agent builds.
- [Model selector](https://docs.replit.com/features/agent/model-selector.md): Use intelligent model routing or choose an available primary model for Replit Agent.
- [App Testing](https://docs.replit.com/features/agent/app-testing.md): Learn how Agent tests your app in a real browser and automatically fixes issues it finds.
- [General Agent](https://docs.replit.com/features/agent/general-agent.md): Learn how General Agent lets you work with any framework, create any output type, and read and write to connected services.

### Publishing

- [Publishing](https://docs.replit.com/features/publishing/overview.md): Learn how to publish your Replit App from the Publishing tool — domain, access, database, monitoring, security, and deployment settings in one place.
- [After you publish](https://docs.replit.com/features/publishing/after-you-publish.md): What happens when you select Publish: the publishing stages, updating your live app, and where to manage it.
- [Custom Domains](https://docs.replit.com/features/publishing/custom-domains.md): Buy, connect, and manage a custom domain for your published Replit app.
- [Who can access your app](https://docs.replit.com/features/publishing/private-deployments.md): Control who can open your published app: public, password protected, workspace only, or invite only. No code changes required.
- [Feedback widget](https://docs.replit.com/features/publishing/feedback-widget.md): Add a feedback widget to your published app so visitors can report issues and ideas you can send straight to Agent for fixes.
- [Deployment types](https://docs.replit.com/features/publishing/deployment-types.md): Compare Autoscale, Static, Reserved VM, and Scheduled deployments and learn when to choose each one for your published app.
- [Machine configuration](https://docs.replit.com/features/publishing/machine-configuration.md): Set the power and cost of the servers that run your published app: CPU, memory, and the maximum number of machines.
- [Project geography](https://docs.replit.com/features/publishing/project-geography.md): Choose where the compute and storage for a published Project are hosted.

### Monitoring

- [Monitoring your app](https://docs.replit.com/features/publishing/monitoring-a-deployment.md): Monitor your published app's uptime, requests, resource usage, and logs. Use production charts to identify issues, then ask Monitoring Agent to investigate.
- [Monitoring Agent](https://docs.replit.com/features/publishing/monitoring-agent.md): Use Monitoring Agent to investigate production alerts, attempt fixes, and automatically republish them. Ask Agent about your published app's logs and metrics.
- [Performance Agent](https://docs.replit.com/features/publishing/performance-agent.md): Scan your app for slow requests and database bottlenecks with Performance Agent, then fix the issues with Agent and republish.

### Database

- [Database](https://docs.replit.com/features/data-and-storage/sql-database.md): Learn how to use Replit's built-in SQL database to store and retrieve data for your app.
- [Development and production databases](https://docs.replit.com/features/data-and-storage/development-and-production.md): Understand your app's two databases: the development database you build with and the production database that serves your published app.
- [How Publish updates your production database](https://docs.replit.com/features/data-and-storage/publish-database-changes.md): Learn how Replit compares, validates, and applies your development database schema changes to production when you publish your app.

- [Monitor your database](https://docs.replit.com/features/data-and-storage/monitor-your-database.md): Use the Monitoring tab to see which queries are running against your production database right now, and which ones are slowing your app down.
- [Connection details](https://docs.replit.com/features/data-and-storage/connection-details.md): Find your database's connection string, understand how credentials stay secure, and connect external tools.
- [Data recovery](https://docs.replit.com/features/data-and-storage/data-recovery.md): Restore your development database to a checkpoint, or bring your production database back to an earlier point in time or a daily backup.

### Users & Auth

- [Users & Auth](https://docs.replit.com/features/auth-and-identity/overview.md): Manage the people who sign in to your app and choose how they sign in, with Replit Auth or Clerk.
- [Replit Auth](https://docs.replit.com/features/auth-and-identity/authentication.md): Learn how to add user authentication to your app with Replit Auth — users sign in with their Replit accounts, with zero setup required.
- [Clerk Auth](https://docs.replit.com/features/auth-and-identity/clerk-auth.md): Learn how Clerk Auth gives your Replit app its own dedicated authentication system with customizable branding, independent user accounts, and SSO providers.
- [Add SSO to your app (Clerk)](https://docs.replit.com/features/auth-and-identity/single-sign-on.md): Let your app's users sign in with their company identity provider, such as Okta or Microsoft Entra ID, through the Clerk dashboard, plus multi-factor authentication and session controls.
- [Migrate from Replit Auth to Clerk](https://docs.replit.com/features/auth-and-identity/migrate-auth-to-clerk.md): Use Agent to move an existing Replit Auth app to Clerk Auth while preserving your app's user data.
- [Sign-in providers](https://docs.replit.com/features/auth-and-identity/sign-in-providers.md): Set up custom OAuth credentials for Google, GitHub, Apple, and X sign-in on apps that use Clerk Auth.
- [Plan a custom auth migration](https://docs.replit.com/features/auth-and-identity/custom-auth-migration.md): Plan a safe migration from a custom authentication system to Clerk Auth while preserving your app's user data and access rules.

### Security Center

- [Project Security Center](https://docs.replit.com/features/security/project-security-center.md): Choose a security scan, review findings, and fix vulnerabilities before you publish your Replit App.
- [Security scan levels](https://docs.replit.com/features/security/security-scan-levels.md): Compare Security Center Levels 1, 2, and 3 to choose dependency checks, an Agent source-code review, or a black-box test of your running app.
- [Agent security scans](https://docs.replit.com/features/security/agent-security-scans.md): Run a source-code security review, assess findings, fix vulnerabilities with Agent, and verify the fixes.
- [Black-box pen tests](https://docs.replit.com/features/security/black-box-pen-tests.md): Run a Level 3 security scan that reviews source code and tests the running app through browser and network interactions.
- [Workspace Security Center](https://docs.replit.com/features/security/workspace-security-center.md): Scan your workspace's projects for vulnerabilities, view CVE details by severity, fix issues with Agent, and export SBOMs for compliance.
- [Package Firewall](https://docs.replit.com/features/security/package-firewall.md): Package Firewall blocks malicious and compromised packages at install time, before any code reaches your app. On by default, powered by Socket.
- [Set up Tunnels](https://docs.replit.com/features/security/tunnels.md): Set up Replit Tunnels to connect projects to private TCP services, deploy a connector with Docker or Helm, verify endpoints, and manage enrollment keys.
- [Security](https://docs.replit.com/features/security/overview.md): Learn why security matters when you publish from Replit, where Security tools live, and which page to use for project or workspace reviews.
- [Geography](https://docs.replit.com/features/security/geography.md): Choose where workspace and published app infrastructure is hosted to support data residency and reduce latency.
- [Security concepts](https://docs.replit.com/features/security/concepts.md): Glossary of security terms used across Replit's security tools — CVE, severity, SBOM, exposure, Fix with Agent, Republish, Package Firewall, and Auto-Protect.
- [Replit shared responsibility model](https://docs.replit.com/features/security/shared-responsibility-model.md): Understand how security, compliance, and operational responsibilities are split between Replit and you when you build, ship, and run apps on Replit.
