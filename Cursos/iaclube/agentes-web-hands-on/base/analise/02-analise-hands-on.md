# Analise Critica 360 - Agentes Web Hands-on

## 1. Sumario Executivo

**Nota: 8/10.** A v1 oferece tarefas seguras e observaveis, mas precisa tornar a preparacao independente da ferramenta, acrescentar verificacoes formativas nativas, detalhar breadcrumbs, explicitar planos alternativos quando a conta nao possui o recurso e robustecer o Projeto Final.

## 2. Pontos Positivos (Fortalezas)

- Usa sites publicos e sandboxes sem envio.
- Define resultados observaveis e formas de desfazer.
- Introduz permissoes antes da primeira tarefa.
- Inclui pausa, takeover, verificacao e registro.

## 3. Pontos Negativos e Gargalos (Debilidades)

- O aluno pode nao encontrar o recurso por plano, regiao ou politica do workspace.
- Alguns caminhos de menu variam; afirmar rotulo unico cria friccao.
- Falta Knowledge Check em cada oficina para o Rise.
- A Oficina 2 nao define tabela-modelo completa.
- O Projeto Final tem pouco tempo para execucao real; deve funcionar como consolidacao e checklist, nao como pesquisa extensa ao vivo.
- Faltam objetivos/habilidades, sugestoes de producao visual e troubleshooting ligado a cada bloqueio.

## 4. Matriz de Solucoes e Melhorias

| Gargalo | Onde ocorre | Correcao concreta | Prioridade |
|---|---|---|---|
| Recurso indisponivel | Modulo 0/Oficina 1 | oferecer caminho Comet ou Work e atividade de observacao se nenhum estiver disponivel | Alta |
| Menu instavel | todas | usar breadcrumb validado quando houver e marcar conferencia na UI | Alta |
| Verificacao nativa ausente | oficinas 1-4 | incluir uma decisao de multipla escolha com feedback | Alta |
| Tabela indefinida | oficina 2 | fornecer colunas criterio, achado, titulo, URL, data e status | Media |
| Projeto superdimensionado | projeto | fornecer ficha pre-preenchida e limitar auditoria a cinco afirmacoes | Alta |
| Descricao de aula | todas | separar objetivos e habilidades; incluir pontos de controle e telas sugeridas | Media |

## 5. Roadmap de Expansao

Cabem no curso: prompt LIMITE, allowlist, takeover, prompt injection e log. Ficam para curso posterior: sistemas internos, dados regulados, compras reais, automacao em escala, integracao com APIs e resposta corporativa a incidente.
