# Extrator de SCORM

Lê os pacotes SCORM (Articulate Rise 360) de `Cursos/` e gera uma ficha de cada curso e o `Cursos/registro-de-cursos.json`.

**Abrir a interface:** duplo clique em [`abrir-interface.bat`](abrir-interface.bat) ou

```bash
uv run python -m extrator_scorm
```

Linha de comando, opções e problemas comuns: [`scripts/documentacao/extrator-scorm.md`](../documentacao/extrator-scorm.md).
Como funciona por dentro: [`scripts/documentacao/extrator-scorm-tecnico.md`](../documentacao/extrator-scorm-tecnico.md).
