3. PRIMEIROS PASSOS (passo a passo com origem dos menus)
----------------------------------------------------------------

3.1 ChatGPT Images — web (origem: ajuda EN [1])
Criar:
1. Em chatgpt.com, escreva o pedido ("Crie uma imagem de...") ou
   selecione "More" → "Images" e digite o prompt.
2. Para mudar formato, use o seletor de proporção ("aspect ratio picker")
   ou escreva a proporção no prompt.
3. A geração pode levar alguns minutos; é possível continuar usando o
   ChatGPT enquanto isso.
A partir de template:
1. Abra a barra lateral → "Images" → "Templates".
2. Escolha categoria e template; personalize; envie.
3. Responda às perguntas de acompanhamento (estilo etc.); se houver opção
   de upload, adicione referência.
Editar (editor):
1. Selecione uma imagem na conversa ou em "Images".
2. "Select" para destacar a área; "Aspect ratio" para regenerar em outra
   proporção; "Undo"/"Redo"; "Cancel"; "Save".
3. Ou descreva a edição sem seleção na caixa de texto.
Aviso oficial: "Highlights are not always precise, and edits may extend
beyond the area you selected." [1]
Gerenciar: todas as imagens ficam em "Images"; abrir imagem → "Copy",
"Save" (baixar), "Share". Para apagar da biblioteca, apague a conversa
(••• → "Delete"). [1]
Referência salva: envie foto, peça para salvar como referência, dê um
nome; depois use "@nome" no prompt. [1][2]
GIF: peça "um GIF em loop" e descreva o que se move; não edita GIF
enviado pelo usuário. [1]

3.2 ChatGPT Images — celular (origem: ajuda EN [1])
- Esboço: na caixa de mensagem digite "@" → "Sketch"; desenhe; confirme
  (✓); escreva instruções; envie.
- Toque na imagem para tela cheia: "Edit", "Select" (com slider de
  tamanho do pincel, "Undo"/"Redo", "Next"), comentários; controles
  "Resize" e "Remove" no mobile.
- Compartilhar prompt: "Share" → "Prompt template" → "Copy link".

3.3 Google Pics (origem: ajuda PT-BR [11][13][14])
Criar do zero:
1. No computador, abra o Google Pics (docs.google.com/images/create [10]).
2. Escreva o comando na barra inferior → "Enviar".
3. Opcional: "Adicionar imagens" para referências.
4. Escolha uma das versões no painel à esquerda; "Tentar de novo" para
   mais opções.
Editar com comando geral: caixa de texto → descrever → "Enviar".
Editar elemento: passar o cursor → clicar no elemento (ex.: "Piso") →
comando no pop-up → "Adicionar" → "Aplicar" (barra inferior); até cinco
mudanças; "Aplicar edições" aplica todas.
Editar área: clicar e arrastar para selecionar → comando → "Adicionar" →
"Aplicar".
Editar texto na imagem: clicar no texto → digitar novo texto ou estilo →
"Salvar" → "Aplicar". O Pics detecta texto automaticamente.
Cortar/girar/proporção: "Cortar" no topo → arrastar bordas; girar com o
controle; proporção no menu (16:9, 1:1, 4:3); "Redefinir"; "Sair".
Zoom: menu "Ajustar".
Referência de estilo: "Estilo" na parte de baixo → upload/Drive/Fotos
(só em inglês).
Baixar: canto superior direito "Baixar" → "Original", "JPEG 2K" ou
"JPEG 4K". Usuários Workspace Experiments: só "Original". [14]
Imprimir: canto superior esquerdo (seta) → "Imprimir". [14]
Compartilhar: "Compartilhar" → pessoas/grupos → "Leitor" ou "Editor" →
"Enviar". [14] (rótulos PT podem variar; EN: "Viewer"/"Editor"/"Send")

3.4 Google Pics dentro do Slides/Docs (origem: ajuda EN/PT [16])
1. Abra a apresentação → clique na imagem → "Edit image" ("Editar
   imagem"). Se abrir a barra lateral, a conta talvez ainda não tenha
   acesso.
2. Edite no Pics aberto dentro do Slides; pode minimizar e continuar.
3. "Replace image" (canto superior direito) para inserir no slide.

3.5 App Gemini (origem: ajuda PT-BR [18])
Gerar: gemini.google.com → "Abrir barra lateral" → "Imagens" → escolher
modelo/template ou digitar comando. Dica oficial: começar com "desenhe",
"gere", "crie"; dizer o estilo; detalhar.
Editar: "Abrir barra lateral" → "Biblioteca" → clicar na imagem (ou enviar
do dispositivo) → "Conversa" → digitar → "Enviar".
Refazer com Pro (plano pago): "Mais" → "Refazer com Pro" (rótulo EN
"Redo with Pro"). [18]
Baixar: passar o cursor → "Baixar no tamanho original". Exportar: "Mais"
→ "Exportar para o Docs". [18]

3.6 Critério de êxito do primeiro uso [SUGESTÃO]
O aluno consegue: (a) gerar 1 imagem a partir de brief; (b) pedir 1
variação; (c) fazer 1 edição localizada; (d) mudar proporção; (e) baixar;
(f) localizar a imagem depois (Images/Biblioteca/Drive).

4. GLOSSÁRIO PARA LEIGOS
----------------------------------------------------------------
[SUGESTÃO, salvo indicação] Definições didáticas:
- Prompt/comando: o texto que descreve a imagem desejada.
- Brief: descrição do objetivo, público e uso da imagem antes do prompt.
- Texto-para-imagem: gerar imagem só a partir de texto.
- Imagem de referência: foto/arte enviada para guiar sujeito, estilo,
  cor ou composição. [11][22]
- Edição localizada / inpainting: mudar só uma parte. No ChatGPT, via
  "Select"; no Pics, por elemento ou área. [1][13]
- "Mascaramento semântico": o texto define a área a editar ("remova o
  homem da foto"). [22] [CONFIRMADO]
- Variação: outra versão do mesmo pedido.
- Proporção (aspect ratio): relação largura:altura (1:1, 4:5, 16:9, 9:16).
- Resolução: quantidade de pixels (1K ≈ 1024 px no lado maior; 2K; 4K).
- Upscale: aumentar a resolução (Pics: 2K/4K). [10]
- Fundo transparente: fundo sem cor (canal alfa); exige PNG/WebP. "Um
  xadrez desenhado não é transparência." [9] [CONFIRMADO]
- Consistência de personagem: manter a mesma aparência em várias imagens.
- Artefato: defeito típico (mãos, dentes, texto embaralhado, objetos
  fundidos).
- Alucinação visual: elemento inventado que parece plausível (ex.:
  anatomia errada). [38]
- C2PA / Content Credentials: metadados padronizados de procedência. [4][22]
- SynthID: marca d'água invisível do Google DeepMind. [22][23]
- Marca d'água visível: selo visível (ex.: brilho do Gemini). [24]
- Deepfake: imagem/vídeo realista que faz parecer que uma pessoa real
  fez/disse algo que não ocorreu.
- Alt text (texto alternativo): descrição para leitores de tela. [26]
- Imagem decorativa: não acrescenta informação; alt vazio. [26]
- Sprite sheet: grade de quadros usada para animar (exemplo OpenAI). [3]
- Thinking / raciocínio: modo em que o modelo planeja, pesquisa e
  refina antes de gerar. [4]

7. BOAS PRÁTICAS E PROMPTS OFICIAIS

7.1 Google (Pics [15] e guia Nano Banana [22])
[CONFIRMADO] Fórmula texto-para-imagem: [Sujeito] + [Ação] +
[Local/contexto] + [Composição] + [Estilo].
[CONFIRMADO] Fórmula com referências: [Imagens de referência] +
[Instrução de relação] + [Novo cenário].
[CONFIRMADO] Boas práticas: ser específico; definir cena (ambiente, hora,
clima, luz); nomear estilo; controlar câmera (close, plano aberto,
contra-plongée, profundidade de campo rasa, grande-angular, macro);
palavras-chave fortes; materiais e texturas ("tweed azul-marinho" em vez
de "paletó"); desenhar a luz (três pontos, chiaroscuro, golden hour);
gradação de cor e filme; iterar.
[CONFIRMADO] Enquadramento positivo: descrever o que se quer ("rua vazia")
em vez do que não se quer ("sem carros"); exclusões ainda são possíveis.
[CONFIRMADO] Texto na imagem: aspas no texto exato; tipografia por linha;
escrever o prompt num idioma e indicar o idioma-alvo para tradução;
abordagem "texto primeiro" (definir o texto na conversa, depois a imagem).
[CONFIRMADO] Edição: dizer o que muda E o que fica igual.
[CONFIRMADO] Começar com verbo forte que indique a operação.
[CONFIRMADO] Exemplo oficial (Pics/guia): frasco de hidratante com três
linhas — "GLOW", "10% OFF", "Your First Order" — com fontes distintas, e
depois traduzir para coreano e árabe. [15][22]
[CONFIRMADO] Exemplo PT da ajuda do Pics: "Dessature um pouco a foto e
adicione tons mais frios às sombras para um visual premium." [13]

7.2 OpenAI (Cookbook [9], ajuda [1])
[CONFIRMADO] Organizar pedidos complexos em seções: cena, sujeito,
detalhes, restrições.
[CONFIRMADO] Pessoas e ações: enquadramento, escala, olhar, interação
("corpo inteiro visível, pés incluídos").
[CONFIRMADO] Edições: mudar uma coisa por vez e listar o que preservar;
excluir texto/marca d'água indesejados.
[CONFIRMADO] Referências numeradas com papel (sujeito, estilo, roupa,
fundo).
[CONFIRMADO] Iterar devolvendo a saída anterior; usar "mesmo estilo de
antes" com moderação (pode derivar).
[CONFIRMADO] Texto exato entre aspas + posição + tipografia; pedir "sem
texto extra"; conferir ortografia e legibilidade.
[CONFIRMADO] Consistência: reutilizar a imagem gerada e repetir as
restrições de aparência; verificar a imagem final e as intermediárias.
[CONFIRMADO] Esboço→render: "Do not add new elements or text".
[CONFIRMADO] Ajuda: "Be specific about the details that matter" (ex.:
pôster — para que serve e qual texto incluir). [1]

7.3 Anatomia de um bom brief/prompt [SUGESTÃO, apoiada em 7.1–7.2]
1 Objetivo (para que serve) · 2 Público · 3 Contexto/canal (post, slide,
cartaz A4) · 4 Assunto principal · 5 Ação · 6 Composição/enquadramento ·
7 Estilo (foto, ilustração plana, aquarela) · 8 Luz · 9 Câmera/lente ·
10 Paleta/identidade (cores HEX, fonte) · 11 Texto exato entre aspas ·
12 Proporção e resolução · 13 Restrições (o que preservar; sem logos;
sem pessoas reais; diversidade) · 14 Critério de aceite.
Modelo de prompt [SUGESTÃO]:
"Crie [tipo de imagem] para [uso/canal], público [x]. Cena: [...]. Sujeito:
[...] fazendo [...]. Composição: [plano, posição, espaço livre para
texto]. Estilo: [...]. Luz: [...]. Cores: [...]. Texto exato: "[...]" em
[fonte/peso], no [posição]. Proporção [4:5]. Restrições: sem outros textos,
sem marcas, sem pessoas reais identificáveis."

7.4 Fundamentos visuais para leigos [SUGESTÃO; vocabulário de câmera
confirmado em 22]
- Enquadramento: plano geral (contexto), médio (pessoa da cintura para
  cima), close (emoção/detalhe), detalhe (objeto).
- Composição: regra dos terços; ponto focal único; espaço negativo para
  título; linhas que guiam o olhar.
- Hierarquia: um elemento dominante, um secundário, o resto apoio.
- Cor: paleta de 2–3 cores + neutro; cores com significado cultural.
- Contraste: texto sobre fundo precisa de contraste alto (WCAG pede 4,5:1
  para texto normal [VERIFICAR: não baixado; padrão WCAG 2.x]).
- Tipografia em imagem: poucas palavras; fonte legível; tamanho mínimo
  para leitura no celular.
- Proporção por destino: 1:1 ou 4:5 (feed), 9:16 (stories), 16:9
  (slide/vídeo), A4 ≈ 1:1,414 (impressão).
- Resolução: web/apresentação ≈ 1K–2K; impressão pede mais pixels
  (≈300 ppi no tamanho final é prática gráfica comum [VERIFICAR]).
- Consistência: mesma paleta, luz, estilo e personagem em uma série.

Erros típicos de aluno [SUGESTÃO] e correção:
- Prompt vago → usar modelo de brief (7.3).

- Texto longo na imagem → poucas palavras; diagramar texto fora (slide).

- Fundo "transparente" em JPEG → usar PNG/ferramenta que suporte alfa.
- Confiar em infográfico gerado → conferir cada número e rótulo.
- Esquecer alt text → escrever ao exportar.

13. EXERCÍCIOS, OFICINAS E PROJETOS [SUGESTÃO — tudo nesta seção]
----------------------------------------------------------------
13.1 Exercícios curtos (Essentials, 3–8 min cada)
E1 Brief→prompt: transformar "imagem para post de vacinação" em prompt
   com os 14 campos. Êxito: todos os campos preenchidos, sem dado clínico.
E2 Mesma ideia, duas ferramentas: rodar o mesmo prompt no ChatGPT e no
   Gemini/Pics; comparar aderência ao brief em tabela de 5 critérios.
E3 Uma mudança por vez: pedir 3 iterações mudando só luz, depois só cor,
   depois só enquadramento. Êxito: o resto permanece.
E4 Texto legível: gerar cartaz com "Semana da Leitura" entre aspas;
   conferir ortografia; corrigir.
E5 Proporção: regenerar a mesma imagem em 1:1, 9:16 e 16:9.
E6 Caça-artefatos: lista de verificação (mãos, olhos, texto, sombras,
   objetos fundidos) em 3 imagens.
E7 Alt text: escrever alt de 1 imagem informativa e decidir se outra é
   decorativa (árvore W3C).
E8 Viés: gerar "uma pessoa médica" e "uma pessoa enfermeira"; anotar
   padrões; reescrever restrições.
E9 Direitos: classificar 6 pedidos (logo de marca famosa, estilo de
   artista vivo, foto de colega, personagem de desenho, paisagem
   genérica, mascote próprio) em "ok / ok com cuidado / não".
E10 Privacidade: localizar e explicar "Improve the model for everyone"
   (ChatGPT) e o histórico do Gemini.

13.2 Oficinas (Hands On, 4 × 12–18 min)
O1 Imagem editorial: brief → 3 variações → escolher → refinar → editar
   região → exportar 16:9 para slide. Entrega: imagem + prompt final +
   alt text.
O2 Infográfico simples (ex.: "4 passos para lavar as mãos"): texto
   primeiro, depois imagem; conferir cada rótulo contra fonte oficial.
   Entrega: infográfico + lista de conferência.
O3 Personagem/mascote consistente: criar mascote fictício, salvar como
   referência (@nome no ChatGPT ou referência no Pics/Gemini), gerar 3
   cenas mantendo aparência. Entrega: série de 3 + critérios.
O4 Material de saúde para paciente (sem diagnóstico): cartaz de
   orientação genérica (ex.: "chegue 15 min antes", "traga documento"),
   linguagem simples, contraste alto, sem anatomia, revisão por
   profissional simulada. Entrega: cartaz + checklist de segurança.

13.3 Projeto final
P1 Kit visual de 4 peças para um tema escolhido (marketing, aula ou
   sala de espera): 1 imagem principal, 2 variações de proporção, 1
   infográfico simples; tudo com prompt registrado, alt text, checklist
   de direitos/consentimento/viés e decisão de rotulagem.
Rubrica (0–2 cada): aderência ao brief; consistência visual;
legibilidade de texto; qualidade técnica (artefatos, resolução,
proporção); acessibilidade (contraste, alt); responsabilidade (direitos,
privacidade, viés, saúde); documentação (prompts, ferramenta, data).
