# Dados com Python e IA Para Leigos — Curso Hands-on

*No fim, você terá um script de análise feito por um agente de IA.*

## Antes de Arregaçar as Mangas

Você vai pedir para um agente de IA escrever Python por você.

O que você precisa ter aberto agora:

- Terminal.
- Claude Code ou Codex.

> 🔑 Regra de ouro: deixe o agente trabalhar.

## O Mapa da Mão na Massa

| Oficina | O problema que você vai resolver | Tempo |

| 1 | Instalar tudo | 15 min |

# Oficina 1 — Instale tudo

### 🎯 O Problema

Você precisa de Python e do agente.

### 🧰 O que você vai usar

- Terminal.

### 👐 Mão na massa

1. Instale o Python.
2. Instale o Claude Code com npm.
3. Rode `claude`.

### ✅ Deu certo?

O agente abriu.

### 🚑 Se travar

| Problema | O que fazer |
|---|---|
| Erro de instalação | Reinstale |

Instale o Codex também.
