# ChatGPT Chat Para Leigos — Curso Hands-on

*No fim, você vai ter resolvido um caso de verdade com o ChatGPT, do arquivo ao relatório.*

# Antes de Arregaçar as Mangas

Este curso é mão na massa: você vai usar projetos, arquivos, busca e análise de dados para
resolver um caso completo.

O que você precisa ter aberto agora:

- O ChatGPT no navegador, com sua conta.
- Uma planilha e um PDF quaisquer para testar.

> 🔑 **Regra de ouro:** se a resposta não ficou boa, peça de novo, melhor.

# O Mapa da Mão na Massa

| Oficina | O problema que você vai resolver | Tempo |
|---|---|---|
| 1 | Organizar o trabalho num projeto | 15 min |
| 2 | Tirar respostas de documentos | 15 min |
| 3 | Buscar informação atual | 15 min |
| 4 | Analisar uma planilha | 15 min |
| Projeto Final | Relatório do caso | 20 min |

Cada oficina entrega uma pequena vitória.

---

# Oficina 1 — Monte seu projeto

### 🎯 O Problema

Suas conversas sobre o mesmo assunto ficam espalhadas. Vamos juntar tudo num projeto.

### 🧰 O que você vai usar

- ChatGPT, Projetos.

### 👐 Mão na massa

1. Clique em "Novo projeto".
2. Dê um nome.
3. Adicione instruções.
4. Envie seus arquivos.

### ✅ Deu certo?

O projeto aparece na barra lateral com seus arquivos.

### 🚑 Se travar

| Problema | O que fazer |
|---|---|
| Não acho Projetos | Atualize a página |
| Arquivo não sobe | Tente outro formato |

### 🚀 Quer ir além?

Mova uma conversa antiga para o projeto.

---

# Oficina 2 — Pergunte aos documentos

### 🎯 O Problema

Você tem um PDF longo e pouco tempo.

### 🧰 O que você vai usar

- O projeto da Oficina 1.

### 👐 Mão na massa

1. Abra o projeto.
2. Pergunte: "Resuma o documento em 5 tópicos".
3. Peça os trechos que sustentam cada tópico.

### ✅ Deu certo?

Você tem um resumo com trechos.

### 🚑 Se travar

| Problema | O que fazer |
|---|---|
| Resposta genérica | Cite o nome do arquivo |

### 🚀 Quer ir além?

Peça uma tabela com prazos do documento.

---

# Oficina 3 — Busque o que é atual

### 🎯 O Problema

O documento é de ontem; você precisa saber o que mudou hoje.

### 🧰 O que você vai usar

- Busca na web.

### 👐 Mão na massa

1. Ative a busca.
2. Pergunte sobre uma novidade do seu tema.
3. Abra as fontes.

### ✅ Deu certo?

Resposta com links que abrem.

### 🚑 Se travar

| Problema | O que fazer |
|---|---|
| Sem fontes | Peça "cite as fontes" |

### 🚀 Quer ir além?

Compare duas fontes.

---

# Oficina 4 — Faça a planilha falar

### 🎯 O Problema

Uma planilha cheia de números e nenhuma conclusão.

### 🧰 O que você vai usar

- Uma planilha CSV de dados abertos.

### 👐 Mão na massa

1. Envie a planilha.
2. Peça um resumo.
3. Peça uma tabela e um gráfico.
4. Baixe o gráfico.

### ✅ Deu certo?

Gráfico baixado.

### 🚑 Se travar

| Problema | O que fazer |
|---|---|
| Limite de uploads | Espere ou assine |

### 🚀 Quer ir além?

Peça uma segunda visualização.

---

# Projeto Final — Relatório de uma página

### 🎯 A missão

Juntar documento, busca e planilha num relatório.

### 👐 Mão na massa

1. Abra o projeto.
2. Peça o relatório usando tudo.
3. Revise.

### 🏁 Como saber que terminou

- [ ] Relatório de uma página
- [ ] Fontes citadas
- [ ] Gráfico incluído

# A Parte dos Dez — Dicas para o dia a dia

1. Seja específico.
2. Dê contexto.
3. Peça formato.
4. Use projetos.
5. Use a busca.
6. Confira as fontes.
7. Use o chat temporário.
8. Edite a mensagem em vez de recomeçar.
9. Peça para resumir a conversa.
10. Compare com outra IA.
