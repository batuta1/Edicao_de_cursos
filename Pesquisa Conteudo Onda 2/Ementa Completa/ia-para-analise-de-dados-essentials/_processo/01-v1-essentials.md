| Natureza | Curto, introdutório e prático |

### Objetivo Geral

O curso tem por finalidade capacitar o participante a analisar uma base de dados com o recurso de
análise de dados do ChatGPT, do carregamento do arquivo à interpretação dos resultados. Como
produto final, o participante entrega uma análise curta de uma base pública, com gráfico e
conclusões.

### Competências a Desenvolver

Concluído o curso, o participante deverá demonstrar capacidade de:

1. Carregar uma base de dados no ChatGPT.
2. Explorar a base com estatística descritiva.
3. Gerar gráficos adequados.
4. Interpretar resultados.

# Módulo 1 — O que é análise de dados com IA

> Ponto de partida.

### Objetivos de Aprendizagem

Ao final deste módulo, o participante deverá ser capaz de:

1. Definir análise de dados com IA.
2. Identificar as ferramentas disponíveis.
3. Reconhecer os usos possíveis.

### Texto Descritivo

A análise de dados com inteligência artificial consiste em enviar um arquivo a um assistente e
formular perguntas em linguagem natural. O ChatGPT possui um recurso denominado Advanced Data
Analysis, que permite carregar planilhas e obter resumos, tabelas e gráficos.

Observa-se que esse recurso amplia o acesso à análise de dados para profissionais sem formação em
programação. O Julius AI constitui alternativa especializada.

Recomenda-se ativar o recurso nas configurações antes de iniciar.

### Exercício Prático

**Reconhecimento (5 min)**

1. Acessar o ChatGPT.
2. Localizar a opção de análise de dados.

Critério de êxito: opção localizada.

# Módulo 2 — Carregar e explorar

> Pressupõe o Módulo 1; desloca o foco para o uso.

### Objetivos de Aprendizagem

Ao final deste módulo, o participante deverá ser capaz de:

1. Enviar um arquivo.
2. Solicitar estatísticas descritivas.
3. Identificar valores ausentes.

### Texto Descritivo

O envio de um arquivo é feito pelo ícone de anexo. Formatos aceitos incluem CSV e Excel. Após o
envio, convém solicitar um resumo da base: número de linhas, colunas e tipos.

A estatística descritiva compreende média, mediana e desvio padrão. O ChatGPT calcula esses valores
automaticamente.

### Exercício Prático

**Primeira exploração (10 min)**

1. Baixar uma planilha pública de interesse.
2. Enviá-la ao ChatGPT.
3. Pedir média e mediana de uma coluna numérica.

Critério de êxito: valores obtidos.

# Módulo 3 — Gráficos

> Pressupõe o Módulo 2; desloca o foco para a visualização.

### Objetivos de Aprendizagem

Ao final deste módulo, o participante deverá ser capaz de:

1. Solicitar um gráfico.
2. Escolher o tipo de gráfico.
3. Exportar o gráfico.

### Texto Descritivo

O ChatGPT gera gráficos de barras, linhas, pizza e outros. Gráficos de barras servem para comparar
categorias; de linhas, para séries temporais. O gráfico pode ser baixado.

### Exercício Prático

**Gráfico (10 min)**

1. Pedir um gráfico de barras da base do Módulo 2.
2. Baixar o gráfico.

Critério de êxito: gráfico baixado.

# Módulo 4 — Interpretar resultados

> Pressupõe o Módulo 3; desloca o foco para a interpretação.

### Objetivos de Aprendizagem

Ao final deste módulo, o participante deverá ser capaz de:

1. Interpretar resultados.
2. Distinguir correlação de causalidade.
3. Redigir conclusões.

### Texto Descritivo

A interpretação exige cautela. Correlação não implica causalidade. Recomenda-se pedir ao ChatGPT um
resumo executivo das conclusões e conferir os números.

### Exercício Prático

**Questão de múltipla escolha**

Duas variáveis crescem juntas. Pode-se concluir que uma causa a outra?
(a) Sim. (b) Não necessariamente. (c) Só se o ChatGPT disser.

Gabarito: (b).
