- Uma planilha qualquer.

# Oficina 1 — Entenda a base

### 🎯 O Problema

Você recebeu uma planilha e não sabe por onde começar.

### 🧰 O que você vai usar

- ChatGPT e uma planilha.

### 👐 Mão na massa

1. Abra o ChatGPT.
2. Anexe a planilha.
3. Digite:

> Descreva esta base.

### ✅ Deu certo?

O ChatGPT descreveu as colunas.

### 🚑 Se travar

| Problema | O que fazer |
|---|---|
| Arquivo não sobe | Tente outro formato |
| Resposta estranha | Repita o pedido |

### 🚀 Quer ir além?

Peça um resumo estatístico.

# A Parte dos Dez — Dicas de análise com IA

1. Diga o que quer decidir.
2. Nomeie as colunas.
3. Peça o código.
4. Confira os totais.
5. Use gráficos simples.
6. Desconfie de números redondos.
7. Peça premissas.
8. Não envie dados pessoais.
9. Salve os resultados.
10. Pratique.
