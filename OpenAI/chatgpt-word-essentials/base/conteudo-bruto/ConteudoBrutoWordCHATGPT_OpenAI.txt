Como criar e editar documentos, planilhas e apresentações com o ChatGPT Trabalho
Crie arquivos editáveis a partir de instruções, material de origem ou um modelo existente.

Atualizado: há 5 dias
O ChatGPT Trabalho pode criar ou editar documentos, planilhas, apresentações, relatórios e análises. Comece com instruções, anexe material de origem ou peça ao ChatGPT para seguir um arquivo existente, um deck mestre ou um modelo reutilizável.

A disponibilidade depende do seu plano, das configurações do workspace, do tipo de arquivo e da interface. O ChatGPT Trabalho é compatível com Documentos, Planilhas e Apresentações Google nativos quando o app relevante do Google Workspace está ativado. O aplicativo ChatGPT para desktop também é compatível com o Microsoft Excel por meio do suplemento ChatGPT para Excel. O PowerPoint não está incluído neste fluxo do Trabalho para desktop no lançamento.

Criar um arquivo
Abra o Trabalho e descreva o arquivo que você quer e como pretende usá-lo.

Anexe o material de origem que o ChatGPT deve usar.

Informe o formato de saída e onde o ChatGPT deve criar o arquivo.

Diga o que deve permanecer inalterado, como fórmulas, layout, tom, marca, ordem dos slides ou estrutura da tabela.

Revise o arquivo e peça alterações antes de compartilhá-lo ou usá-lo como base.

Para uma planilha, indique as abas, colunas, fórmulas e gráficos importantes. Para uma apresentação, indique as seções, os tipos de slide e as verificações visuais esperadas.

Usar um arquivo de referência como modelo
Um arquivo de referência dá ao ChatGPT um exemplo para a tarefa atual. Diga ao ChatGPT o que deve seguir e o que deve substituir.

Por exemplo: “Use os slides mestres e a ordem das seções desta apresentação, mas substitua o conteúdo pela pesquisa de clientes anexada.”

Reutilize um modelo
Salve um formato que você usa com frequência e reutilize-o em novos documentos, planilhas e apresentações.

Um modelo combina um arquivo de referência com instruções reutilizáveis. Use um modelo para manter a consistência em trabalhos recorrentes, como briefings de projetos, relatórios semanais ou modelos financeiros, sem precisar explicar o formato toda vez.

Para uma solicitação pontual, basta usar um arquivo de referência. Crie um modelo quando quiser repetir o mesmo fluxo de trabalho.

A disponibilidade depende do seu plano, das configurações do Ambiente de trabalho seguro e de você estar usando o Work na Web ou o Codex no aplicativo ChatGPT para desktop.

Crie um modelo
Comece com um documento do Word (.docx), uma pasta de trabalho do Excel (.xlsx), uma apresentação do PowerPoint (.pptx) ou um link para um arquivo do Documentos, Planilhas ou Apresentações Google.

Para usar uma referência do Google Workspace, conecte o Google Drive com uma conta que tenha acesso ao arquivo. Criar um modelo não altera o arquivo original do Google. O modelo mantém um link para ele para uso futuro.

No Work na Web ou no Codex do aplicativo ChatGPT para desktop, selecione @Template-Creator no campo de mensagem.

Anexe um arquivo de referência ou adicione o link dele no Google Workspace.

Descreva o que deve permanecer igual, o que deve mudar e quais informações você fornecerá para cada novo arquivo.

Envie a solicitação. Se o botão Instalar aparecer com o modelo concluído, selecione-o.

Por exemplo, peça ao ChatGPT para manter os títulos, a estrutura das tabelas e o tom de um briefing de projeto e usar as novas anotações do projeto para preencher o conteúdo.

Na Web, você também pode abrir o Criador de modelos em Biblioteca → Novo → Ver modelos → Criar modelo.

Use um modelo
Na Web ou no Codex do aplicativo ChatGPT para desktop, selecione @Documents, @Spreadsheets ou @Presentations no campo de mensagem para abrir a galeria de Modelos.

Escolha um modelo. Na Web, selecione Usar modelo para adicioná-lo ao seu prompt.

Descreva o arquivo que você quer e forneça o material de origem para esta tarefa.

Revise o prompt e envie-o. A escolha de um modelo não inicia a tarefa automaticamente.

Na Web, você também pode encontrar seus modelos na Biblioteca.

Os modelos criados na Web e os salvos localmente pelo Codex são separados. Eles não são sincronizados automaticamente entre si.

Antes de compartilhar ou usar o arquivo concluído, confira o conteúdo, o layout, as fórmulas e os gráficos. Peça alterações ao ChatGPT se o resultado precisar de ajustes.

Antes de compartilhar um novo arquivo do Google Workspace criado com um modelo, abra-o no Google Workspace e verifique onde ele está salvo e quais são as configurações de compartilhamento.

Um arquivo de referência é um exemplo para uma solicitação. Um modelo combina um arquivo de exemplo, instruções e uma saída esperada para que você possa reutilizar o fluxo de trabalho.

Quais são as restrições de tamanho para upload de arquivos?
Todos os arquivos enviados para um GPT ou para uma conversa do ChatGPT têm um limite rígido de 512 MB por arquivo.

Todos os arquivos de texto e documentos enviados para um GPT ou para uma conversa do ChatGPT têm limite de 2 milhões de tokens por arquivo. Essa limitação não se aplica a planilhas.

Para arquivos CSV ou planilhas, o tamanho do arquivo não pode exceder aproximadamente 50 MB, dependendo do tamanho de cada linha.

Para imagens, há um limite de 20 MB por imagem.

Além disso, há limites de uso:

Cada usuário final tem limite de 25 GB.

Cada organização tem limite de 100 GB.

Observação: um erro será exibido se o limite de um usuário/organização tiver sido atingido.

You do not need Microsoft Copilot or any premium subscription to use AI when writing  Word documents. ChatGPT works well as a writing assistant for Word through a straightforward copy-and-paste workflow, and it handles most of the same tasks — drafting, rewriting, summarising, changing tone — at no cost with the free tier, or with improved quality on ChatGPT Plus. This guide explains how to make it work effectively and includes ten practical prompts you can use straight away.Windows OS

Why ChatGPT Works Well for Word Documents
ChatGPT is a general-purpose AI that is good at working with text. It does not integrate directly with Word like Copilot does, but that is less limiting than it sounds. The core tasks most people actually need — writing a first draft, rewriting a clunky paragraph, shortening a long section, changing the tone of a letter — all work perfectly well through a browser tab and a paste into Word.


The main advantages of using ChatGPT for Word work:

No extra subscription required. The free tier at chat.openai.com covers most writing tasks.
Works with any version of Word, including older versions that do not support Copilot at all.
You are in full control of what you send — you only share what you paste into the chat window.
Easy to iterate — you can ask for adjustments in plain English without menus or settings.
The Basic Workflow
The process for using ChatGPT with Word is simple and consistent regardless of what you are trying to do:

Open ChatGPT in your browser at chat.openai.com. You can sign in with a free account or use it without signing in for basic queries, though signing in preserves your conversation history.
Write your prompt. Describe what you need — a new piece of writing, a rewrite of existing text, a summary, a tone change. Be specific (more on this below).
Paste in any text you want ChatGPT to work with. If you want something rewritten or summarised, paste the relevant text directly into the chat after your instruction.
Copy the output. When ChatGPT responds, select the text and copy it (Ctrl + C).
Paste into Word. Go to your document and paste (Ctrl + V). Use Paste Special > Unformatted Text if you want to paste without bringing in any browser formatting.
Edit and review. Read through the output and adjust. ChatGPT will not know your specific situation perfectly — you will usually need to make some changes.
For longer documents, work section by section rather than trying to write the whole thing in one prompt. This gives you more control and produces better results.

Best Use Cases for ChatGPT and Word
Writing First Drafts
Starting with a blank page is often the hardest part of writing. Give ChatGPT a prompt describing what you need and let it produce a draft. The draft will rarely be perfect, but it breaks the blank-page problem and gives you something to work from. It is much faster to edit an imperfect draft than to write from scratch.Books & Literature


Rewriting Awkward Sentences
Paste a sentence or paragraph that is not working and ask ChatGPT to rewrite it. You can ask for it to be clearer, shorter, more direct, or better phrased. If the first rewrite is not right, ask for another version or give more specific instructions about what is wrong with it.

Making Text Shorter or Clearer
Long, complex documents often need simplifying before they go out. Paste a section and ask: “Make this shorter and easier to read.” ChatGPT will cut filler, reduce jargon and tighten sentences. This is particularly useful for communications aimed at customers or the public where plain English matters.

Changing Tone From Casual to Formal (or Vice Versa)
If you have written something in an informal style but need it to sound more professional — or you have a formal document that needs to be more approachable — pasting it and asking for a tone change takes a few seconds. Specify clearly: “Rewrite this to sound more formal and professional” or “Make this sound friendlier and less corporate.”

Structuring and Outlining
Describe the document you are writing and ask ChatGPT for a suggested structure. For example: “I need to write a proposal for a small business client explaining why they should move their IT to the cloud. What sections should the document include?” Use the outline as a starting point and fill in each section yourself or with further prompts.

Top 10 Prompts for Word Users
These prompts work directly in ChatGPT. Replace the bracketed text with your own details.

Draft a business letter: “Write a professional business letter to a customer informing them that [reason, e.g. our office will be closed over Christmas]. Keep it polite, concise and no longer than three short paragraphs.”
Rewrite more formally: “Rewrite the following text to sound more professional and formal, suitable for a business report: [paste text]”
Summarise into bullet points: “Summarise the following text into five clear bullet points: [paste text]”
Expand bullet points into a paragraph: “Turn the following bullet points into a well-written paragraph: [paste bullets]”
Shorten a section: “Shorten the following text to approximately half its current length without losing the key information: [paste text]”
Simplify for a non-technical audience: “Rewrite the following so that someone with no technical background can understand it easily: [paste text]”
Write an introduction: “Write a one-paragraph introduction for a document about [topic]. The audience is [description] and the document covers [brief summary of content].”
Write an email follow-up: “Write a polite follow-up email to [person/company] about [topic]. I last contacted them [timeframe] and have not received a response.”
Generate section headings: “I am writing a guide about [topic] for [audience]. Suggest eight subheadings that would make a logical structure for the document.”
Check and improve clarity: “Read the following text and identify any sentences that are unclear, too long or poorly structured. Then suggest improved versions: [paste text]”
Asking ChatGPT to Format Output Before Pasting
ChatGPT can output text with Markdown formatting — headings marked with # symbols, bullet points with hyphens, bold text with asterisks. This does not always paste cleanly into  Word. To get cleaner output, ask ChatGPT to format the response specifically for Word:Text & Instant Messaging

“Format the response with headings and bullet points ready to paste into a Word document.”
“Use plain text with no Markdown — just headings in capitals and bullet points with a dash.”
Alternatively, paste the text into Word and then apply Styles manually for consistent formatting.
If you receive output with Markdown symbols and do not want them, use Ctrl + H in Word to find and replace them — for example, find “##” and replace with nothing to remove Markdown heading symbols.

Limitations and When to Edit the Output
ChatGPT produces convincing text quickly but it has real limitations that matter in a business context:

It does not know your business. Any specific details — your company name, pricing, policies, client names — must either be in your prompt or added manually after. Never assume ChatGPT has inserted accurate specifics.
It can generate incorrect facts. Do not trust any statistics, dates, regulations or factual claims in the output without checking them independently.
The tone can be generic. ChatGPT defaults to a fairly neutral, slightly corporate voice. Adjust the output to match your usual communication style before sending anything externally.
It can be repetitive. Longer outputs sometimes repeat the same point in slightly different words. Read through and cut any repetition before using the text.
Always proofread. ChatGPT is not infallible and errors do appear. Read everything before it leaves your desk.
Used as a starting point rather than a finished product, ChatGPT is a genuinely useful writing tool for Word users at any level — whether you are putting together a quick customer email or working through a lengthy business proposal.

GPT-5 proposing edits in Revise, shown as a red/green diff, accepted one by one.
Yes - ChatGPT can edit Word documents, but only by uploading and downloading copies of .docx files. Or, you can take the copy-and-paste approach: copy a paragraph, paste it into the chat, have ChatGPT rewrite it, copy the output, paste it back into Word.

The problem is ChatGPT can't edit documents collaboratively with you, in the same interface. That's where Revise comes in - either as a plugin inside ChatGPT or as a full browser-based editor with GPT-5 built in.

To be clear, ChatGPT reads uploaded Word files well - better than PDFs, which tend to lose structure and reading order - but it only sees the extracted body text, and either way you're shuttling copies back and forth and re-applying formatting by hand. For anything longer than a few paragraphs that loop becomes the bottleneck. Bringing the model to the document instead of the document to the model unlocks a few things:

Whole-document context. The AI can see your entire draft - headings, structure, terminology - so its edits stay consistent instead of treating each paragraph in isolation.

You stay in control. The best setups show every change as a tracked suggestion you can accept or reject, so the AI never silently overwrites your work.
One surface for writing and editing. No alt-tabbing between Word and a chatbot - you brainstorm, draft, and revise in the same place.

Can ChatGPT format a Word document?
In chat, not really: it can describe the styles you should use, or regenerate your file with rudimentary formatting, but it can’t apply styling to the document you have. An editor with the model inside it can - provided the editor itself is up to the job.

Where AI document editors differ most is in how much of Word’s feature set they actually model. Many browser editors handle rich text but not pagination, section breaks, or native tracked changes - so those parts of a .docx are dropped on import and can’t survive the round trip back to Word.

Revise is a full word processor, with support for all the features that Word has. Tracked changes and comment threads, footnotes and endnotes, section breaks with per-section headers and footers, multilevel legal numbering that renumbers live as you edit, a live table of contents, tab stops, watermarks, line numbering, widow and orphan control - with real pagination, so page 47 in Revise is page 47 in Word.

The alternative: a ChatGPT Word add-in
The other way to get ChatGPT in Microsoft Word is the traditional Word add-in from the Microsoft 365 store. If you specifically need to stay inside the Word desktop app, the flow looks like this:

In Word, open Insert → Get Add-ins (or Add-ins → More Add-ins).
Search the Office Store for a ChatGPT or “GPT for Word” add-in and choose Add.
Open the add-in from the ribbon; it appears as a sidebar panel.
Paste or select text, type a prompt, and insert the result back into your document.
This route makes sense when company policy requires desktop Word. The practical limitations to know about: most add-ins only see the text you select, not the whole document, so edits lose surrounding context; results come back as plain text in the sidebar for you to paste in, which can drop character formatting; and they can’t propose edits as tracked changes, so there’s no diff to review - you apply each suggestion by hand.
