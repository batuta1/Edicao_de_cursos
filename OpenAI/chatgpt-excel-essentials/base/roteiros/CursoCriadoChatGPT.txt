# MÓDULO 3

# Automatizando Como um Profissional

## Objetivo

Utilizar Skills, Apps e integrações para acelerar processos complexos.

---

## Aula 1 — O que são Skills?

**Duração:** 25 min

**Skill:** um playbook reutilizável.

Em linguagem simples:

É como salvar uma receita pronta para nunca mais precisar escrever o mesmo prompt.

Como utilizar:

- botão +
- comando @

:contentReference[oaicite:13]{index=13}

---

## Aula 2 — O que são Apps?

**Duração:** 20 min

**App:** conexão entre o ChatGPT e outras fontes de dados autorizadas.

Exemplos:

- arquivos
- bancos de dados
- sistemas internos

:contentReference[oaicite:14]{index=14}

---

## Aula 3 — MCP explicado para Humanos

**Duração:** 15 min

**MCP (Model Context Protocol):**

Um padrão que permite ao ChatGPT acessar ferramentas e dados externos autorizados mantendo controles de segurança e permissões. :contentReference[oaicite:15]{index=15}

---

## Aula 4 — Recursos Avançados

# MÓDULO 4

# Trabalhando com Segurança

## Objetivo

Conhecer limitações, custos e boas práticas antes de utilizar IA em ambientes profissionais.

---

## Aula 1 — Limitações Atuais

**Duração:** 20 min

- histórico separado do ChatGPT
- sem memória compartilhada
- suporte limitado para VBA
- macros podem não funcionar completamente
- revisão humana obrigatória

:contentReference[oaicite:19]{index=19}

---

## Aula 2 — Segurança e Privacidade

**Duração:** 20 min

Explicação simples de:

- criptografia
- Compliance API
- retenção de logs por 30 dias
- Enterprise não utiliza dados para treinamento por padrão

:contentReference[oaicite:20]{index=20} :contentReference[oaicite:21]{index=21}

---

## Aula 3 — Custos e Limites

**Duração:** 20 min

- créditos flexíveis
- uso agêntico
- consumo conforme complexidade
- impacto de planilhas grandes

:contentReference[oaicite:22]{index=22}

---

> ## 🛡️ Aviso dos Sabidos
>
> O ChatGPT é uma excelente ferramenta de produtividade, mas continua sendo um assistente. Revise sempre fórmulas, cálculos, referências e alterações antes de compartilhar ou tomar decisões importantes. :contentReference[oaicite:23]{index=23}

# Encerramento do Curso

## Projeto Final

Construa um modelo automatizado que inclua:

- orçamento mensal;
- limpeza automática de dados;
- explicação das fórmulas;
- criação de cenários;
- resumo das alterações realizadas;
- uso de pelo menos uma Skill;
- uso de um App (quando disponível);
- validação final das alterações antes de salvar.
