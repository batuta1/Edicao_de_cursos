## 3. Resumo Matemático do Curso

$$T_{total} = \sum_{i=1}^{n} t_i = 7 + 16 + 22 + 22 + 16 + 22 = 105 \text{ min}$$

com $n = 19$ atividades. O Projeto Final (22 min) não ultrapassa o dobro de uma oficina (máximo
22 min × 2).

## 4. Análise de Densidade

| Grupo | Tipos | Minutos | % |

| Prática | Setup (7), Pílula (11 × 6 = 66), Avaliação (5 × 4 = 20) | 93 | 89% |

A trilha Hands-on é deliberadamente prática; a teoria necessária vem do Essentials (pré-requisito).
A proporção 40/60 vale para o curso de iniciantes; aqui o desvio é intencional e não exige correção.
