# bagunca

Todos os cursos juntos, uma pasta por tema. Cada tema tem até três subpastas:

- `scorm/`: os pacotes SCORM atuais (Essentials e Hands On). Às vezes é um `.zip`, às vezes a pasta já descompactada (a que tem o `imsmanifest.xml`).
- `roteiros/`: roteiros, roteiros para o Articulate e planos de aula.
- `ementa/`: ementa, carga horária (tabela MET) e o README da ementa.

Quando o material vem separado por nível, há as subpastas `essentials/` e `hands-on/`.

## De onde veio cada coisa

- **Cursos das ondas** (agentes-de-ia, mcp, notebooklm, perplexity, vibe-coding, checagem-de-fontes, revisao-bibliografica, deep-research, chatgpt-chat, gemini-chat, ia-para-analise-de-dados, analise-de-dados-em-python-com-ia e o Hands On de chatgpt-codex e chatgpt-word): SCORM final de `Onda N/01_FINALIZADO_subir-na-LMS/` e ementa e roteiros de `Pesquisa Conteudo Onda N/Ementa Completa/`, na branch `joao` (18 nov 2026).
- **Demais cursos**: versão mais recente de `Cursos/<fornecedor>/<curso>/scorm/vN/` e os arquivos de `base/` (roteiros, plano de aula, ementa e carga horária) desta branch `main`.
- **chatgpt-no-vscode**: só o planejamento (ementa e roteiros), de `Criacao de Cursos/GPT/chatgpt-no-vscode/`. Não há SCORM.
